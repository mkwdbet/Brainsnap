1. 수집하는 정보

Memory Snap은 선택적 계정 기능, 기록 저장, 랭킹 기능을 제공하기 위해 다음 정보를 처리할 수 있습니다.

  • 사용자가 입력한 USER ID
  • 비밀번호 인증 정보: 비밀번호 원문은 저장하지 않고 해시 처리된 인증 정보만 저장합니다.
  • Google 로그인 정보: Google 계정 식별자, 이메일 주소
  • 게임 데이터: 최고 라운드, 코인 수, 연속 정답, 모드별 진행 기록
  • 랭킹 데이터: 랭킹에 표시되는 USER ID, 최고 라운드, 코인 수
  • TOP3 조언 문구: TOP3 사용자가 직접 작성한 한 줄 문구
  • 서비스 운영에 필요한 기본 접속 로그

2. 이용 목적

수집한 정보는 로그인, 계정별 기록 저장, 코인 및 이어하기 기능, 랭킹 표시, TOP3 조언 표시, 서비스 안정성 개선을 위해 사용됩니다.

3. 공개되는 정보

랭킹 화면에는 USER ID, 최고 라운드, 코인 수, TOP3 조언 문구가 표시될 수 있습니다. Google 이메일 주소는 계정 화면에서 본인에게만 표시되며 랭킹에는 표시하지 않습니다.

4. 제3자 제공

Memory Snap은 법령상 필요한 경우를 제외하고 개인정보를 판매하지 않습니다. 서비스 제공을 위해 Google 로그인, AWS 호스팅 및 데이터 저장 인프라를 사용할 수 있습니다.

5. 보관 및 삭제

계정 정보와 게임 기록은 서비스 제공에 필요한 기간 동안 보관됩니다. 사용자는 앱의 계정 화면에서 게임 계정을 삭제할 수 있습니다. 계정을 삭제하면 Memory Snap 서버의 코인, 기록, 랭킹, TOP3 조언 문구가 삭제됩니다. Google로 로그인한 경우에도 Google 계정 자체는 삭제되지 않습니다.

7. TOP3 조언 문구

TOP3 조언 문구는 랭킹 화면에 공개될 수 있는 사용자 작성 텍스트입니다. 욕설, 개인정보, 광고, 도배성 문구는 제한되거나 삭제될 수 있으며, 사용자는 부적절한 문구를 신고할 수 있습니다.

8. 아동 개인정보
